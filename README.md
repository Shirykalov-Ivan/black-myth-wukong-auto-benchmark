# WukongBench

Консольный инструмент на **C# (.NET 8)** для локального автоматизированного запуска
**Black Myth: Wukong Benchmark Tool** из Steam.

Инструмент сам, без участия человека:

1. применяет настроенный профиль и запускает бенчмарк (**CPU-тест**);
2. дожидается результата и разбирает его;
3. применяет другой профиль и запускает бенчмарк (**GPU-тест**);
4. дожидается результата и разбирает его;
5. выводит отчёт: характеристики ПК, результаты обоих проходов и использованные настройки.

---

## Требования

- **Windows 10/11 x64** с установленным [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (или сборка self-contained — см. ниже).
- **Steam** (запущенный) и установленный из Steam **Black Myth: Wukong Benchmark Tool**
  (бесплатный, AppID `3132990`). Инструмент должен быть **хотя бы раз запущен вручную** —
  утилита правит существующий конфиг, а не создаёт новый.
- Права на запись в папке установки бенчмарка (обычно `C:\Program Files (x86)\Steam\...` — запускайте консоль от имени администратора, либо перенесите игру в библиотеку Steam на другом диске).
- Во время прогона **не трогайте мышь и клавиатуру** — инструмент сам нажимает кнопки в меню бенчмарка.

> **Почему нужен запущенный Steam?** У Benchmark Tool есть проверка прав через Steam API
> (`Failed entitlement check with Steam API` без него). Отдельный Denuvo не применяется.

## Сборка и запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (на Linux тоже собирается):

```bash
dotnet build -c Release
dotnet run -c Release --project WukongBench
```

Обычно папка установки определяется автоматически (см. ниже).
Если бенчмарк установлен нестандартно — передайте путь первым аргументом:

```bash
dotnet run -c Release --project WukongBench -- "D:\SteamLibrary\steamapps\common\Black Myth Wukong Benchmark Tool"
```

### Публикация одного exe (без установки .NET у пользователя)

```bash
dotnet publish -c Release -r win-x64 --self-contained false -o ./publish
# или полностью автономный вариант:
dotnet publish -c Release -r win-x64 --self-contained true -o ./publish
```

Результат: `./publish/WukongBench.exe`.

### Готовый .exe

В репозитории лежит собранный self-contained вариант — `publish/WukongBench.exe`
(.NET уже внутри, на целевой машине ничего устанавливать не нужно).
Собран: `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`.

### Демонстрационный режим

Чтобы увидеть формат отчёта, не имея под рукой Benchmark Tool (например, при разработке на Linux),
запустите инструмент с флагом `--demo` — он соберёт реальные характеристики ПК и покажет отчёт
на синтетических данных (в отчёте будет явная пометка о демонстрации):

```bash
dotnet run -c Release --project WukongBench -- --demo
WukongBench.exe --demo
```

**Результаты и отчёт**
инструмент складывает в `%USERPROFILE%\Desktop\WukongBench\results\<дата_время>\`:

- `report.txt` — итоговый отчёт;
- `cpu_raw.json`, `gpu_raw.json` — исходные JSON результатов бенчмарка.

## Как инструмент работает

1. Автоматически находит папку установки Benchmark Tool через Steam:
   - читает `HKCU\Software\Valve\Steam\SteamPath`;
   - парсит `steamapps\libraryfolders.vdf` (библиотеки на других дисках);
   - ищет `steamapps\common\Black Myth Wukong Benchmark Tool`.
2. Делает резервную копию `b1\Saved\Config\Windows\GameUserSettings.ini`.
3. Для каждого прохода:
   1. записывает настройки в конфиг;
   2. запускает `b1\Binaries\Win64\b1-Win64-Shipping.exe`;
   3. проходит меню эмуляцией ввода (Win32 `SendInput`) — заставка → «Тест быстродействия» → «Подтвердить»;
   4. ждёт, пока в `%TEMP%\b1\BenchMarkHistory\Tool\` появится новый JSON результата;
   5. закрывает процесс (kill, чтобы игра не перезаписала конфиг при выходе).
4. Восстанавливает исходный конфиг (также при ошибке и при Ctrl+C; если инструмент был убит —
   конфиг восстановится при следующем запуске).
5. Разбирает результаты и строит отчёт.

## Выбор настроек

Настройки хранятся в `GameUserSettings.ini` в двух представлениях: `UISettingData` (значения меню)
и `[ScalabilityGroups]` (низкоуровневые группы качества Unreal Engine, где значение группы
равно «значение меню − 1»). Инструмент меняет только нужные ключи в обоих блоках.
Значения взяты из рабочих конфигов, а не подобраны наугад: некорректное значение роняет бенчмарк на старте.

Общее для обоих тестов: **полноэкранное окно, VSync выкл, ограничение FPS выкл, генерация кадров выкл
(она вставляет искусственные кадры и завышает результат), размытие в движении выкл,
трассировка лучей выкл** (RT сильно отличается между поколениями видеокарт и искажает сопоставимость).

### CPU-тест — минимальная нагрузка на GPU

| Настройка | Значение |
|---|---|
| Разрешение | 1280×720 |
| Внутренний масштаб рендеринга | 50 % (фактически ~640×360) |
| Все параметры качества (тени, постобработка, освещение…) | минимум |

**Почему так:** при сверхнизком разрешении и минимальном качестве видеокарта перестаёт быть узким
местом — кадр отрисовывается слишком быстро, и итоговый FPS упирается в процессор (драйвер, физику,
загрузку сцены). Именно так CPU-тест показывает производительность процессора, а не видеокарты.

### GPU-тест — максимальная нагрузка на GPU

| Настройка | Значение |
|---|---|
| Разрешение | 1920×1080 |
| Внутренний масштаб рендеринга | 100 % |
| Все параметры качества | максимум |

**Почему так:** высокое разрешение на полном масштабе рендеринга и максимальные эффекты (тени,
глобальное освещение, отражения, постобработка) делают видеокарту почти всегда узким местом —
средний FPS и время кадра показывают именно производительность GPU.

Обоснование каждого профиля также выводится в сам отчёт.

## Что в отчёте

- **Характеристики ПК**: ОС, CPU (из реестра) + логические ядра, объём ОЗУ, список видеокарт
  с объёмом памяти и версией драйвера.
- **Результаты проходов**: FPS (средний/мин/макс/5-й процентиль), загрузка CPU и GPU,
  среднее время кадра по CPU и по GPU, **доля кадров, где процессор считал кадр дольше видеокарты**
  (подтверждает, что CPU-тест действительно упёрся в процессор), использованная видеопамять.
- **Применённые настройки** (по данным самого бенчмарка) + самопроверка: если игра применила другие
  значения, инструмент предупредит об этом.

Исходные JSON результатов (`FPSAvg`, `FPSMin`, `FPS95`, `CPUAvg`, `GPUAvg`, ~10 000 покадровых
записей `Records`) сохраняются рядом с отчётом.

## Ограничения

- Эмуляция ввода реализована через Win32 API (`SendInput`), поэтому **работает только на нативных
  Windows**. Под WINE/Linux прохождение меню невозможно — инструмент честно сообщит об этом.
- Прохождение меню «слепое» (эталонные координаты точек экрана). Если будущие версии бенчмарка
  изменят расположение кнопок, координаты в `BenchmarkRunner.cs` нужно будет обновить.
- Автоматическое создание конфига не предусмотрено: сначала запустите бенчмарк вручную один раз.
- Сборка возможна и на Linux (кроссплатформенный .NET 8), но запуск бенчмарка — только на Windows.

## Структура

```
WukongBench/
├─ WukongBench.sln
├─ README.md
└─ WukongBench/
   ├─ Program.cs             — оркестрация: определение установки, проходы, отчёт
   ├─ SteamGameLocator.cs    — поиск папки установки через реестр Steam и libraryfolders.vdf
   ├─ SettingsFile.cs        — бэкап/восстановление/применение GameUserSettings.ini
   ├─ BenchmarkProfile.cs    — профили настроек CPU- и GPU-теста
   ├─ NativeInput.cs         — Win32: активация окна, клики, клавиши
   ├─ BenchmarkRunner.cs     — запуск, обход меню, ожидание результата
   ├─ ResultWatcher.cs       — отслеживание новых файлов результатов в %TEMP%
   ├─ BenchmarkResult.cs     — модель JSON результата бенчмарка
   ├─ SystemInfo.cs          — характеристики ПК (реестр + Win32)
   └─ ReportPrinter.cs       — форматирование отчёта
```
